## 1. 연말정산이란

회사는 매달 월급을 줄 때 **간이세액표**에 따라 소득세를 미리 떼어 국가에 낸다(원천징수).
간이세액표는 월급과 부양가족 수만 보고 정한 평균값이라, 내가 1년 동안 실제로 쓴
카드·의료비·연금저축 같은 공제는 반영되지 않는다.

**연말정산은 다음 해 초에 1년치 실제 세금을 다시 계산해서, 미리 낸 세금과의 차이를
돌려받거나(환급) 더 내는(추가납부) 절차다.**

```
1년 동안 미리 낸 세금(기납부세액)  vs  실제로 내야 할 세금(결정세액)
          많이 냈으면 → 환급
          적게 냈으면 → 추가납부
```

- 대상: 근로소득이 있는 사람. 회사(원천징수의무자)가 정산을 대신 해 준다.
- 근로소득 말고 다른 소득(사업·임대·일정 규모 이상 금융소득 등)이 있으면 5월
  종합소득세 신고를 따로 한다. 이 가이드는 **근로소득만 있는 경우**를 다룬다.
- 지방소득세는 소득세의 10% 가 따라붙는다. 환급·추가납부도 같은 비율로 붙는다.

## 3. 계산 구조 한눈에

앱의 공제 트래커가 다루는 항목은 ③(소득공제)과 ④(세액공제) 안에 있다.

```
① 기본정보      부양가족 · 자격 요건 (12월 31일 기준)

② 소득          총급여  = 연간 급여 − 비과세소득
                − 근로소득공제
                = 근로소득금액

③ 소득공제      − 인적공제 · 연금보험료공제 · 특별소득공제 · 그 밖의 소득공제
                = 과세표준
                × 기본세율
                = 산출세액

④ 세액감면·공제 − 세액감면 · 세액공제
                = 결정세액 (0 미만이면 0)

⑤ 기납부세액    − 1년 동안 원천징수된 소득세 (종전 근무지 포함)

⑥ 결과          = 차감징수세액   음수면 환급, 양수면 추가납부
                + 지방소득세 (소득세의 10%)
```

**소득공제와 세액공제의 차이**가 핵심이다.

- **소득공제**는 세금을 매기는 금액(과세표준)을 줄인다. 효과는 공제액 × 내 한계세율이다.
  세율 15% 구간인 사람이 100만원을 소득공제받으면 세금이 15만원 준다.
- **세액공제**는 계산된 세금에서 직접 뺀다. 100만원 × 공제율 15% 면 세금이 15만원 준다.
  소득 수준과 상관없이 효과가 같다.
- 결정세액은 0 아래로 내려가지 않는다. **이미 0 이면 공제를 더 받아도 환급이 늘지 않는다.**
  미리 낸 세금(기납부세액)보다 더 돌려받을 수는 없다는 뜻이다.

## 4. 단계별 상세

### ① 기본정보 — 부양가족과 요건

**기본공제 대상자**(1명당 150만원 소득공제). 본인은 항상 포함된다.

| 관계 | 나이 요건 | 소득 요건 |
| --- | --- | --- |
| 배우자 | 없음 | 연간 소득금액 100만원 이하(근로소득만 있으면 총급여 500만원 이하) |
| 부모·조부모(직계존속) | 60세 이상 | 같음 |
| 자녀·손자녀(직계비속) | 20세 이하 | 같음 |
| 형제자매 | 20세 이하 또는 60세 이상 | 같음 |

- 장애인은 나이 요건을 보지 않는다.
- 한 사람은 한 명에게만 기본공제를 받을 수 있다(맞벌이 부부가 자녀를 나눠 받는 식).
- 나이는 귀속연도 12월 31일 기준이다. 그 해에 요건을 한 번이라도 충족했으면 된다.

**추가공제**(기본공제 대상자 중 해당자)

| 항목 | 공제액 |
| --- | --- |
| 경로우대(70세 이상) | 1명당 100만원 |
| 장애인 | 1명당 200만원 |
| 부녀자(소득금액 3천만원 이하 여성 중 요건 충족) | 50만원 |
| 한부모 | 100만원 (부녀자와 중복이면 한부모만) |

**자격 요건**(뒤 단계에서 쓰인다): 무주택 세대주 여부(주택청약·주택자금·월세),
중소기업 취업자 감면 대상 여부, 혼인신고일, 출산·입양.

### ② 소득 — 총급여와 근로소득공제

**총급여** = 1년간 받은 급여·상여·수당 − 비과세소득. 세후 실수령액이 아니라 세전 금액이다.
급여명세서의 "지급 합계" 와 원천징수영수증의 총급여 칸에서 확인한다.

자주 쓰는 비과세: 식대 월 20만원, 자가운전보조금 월 20만원, 6세 이하 자녀 보육수당 월 20만원,
회사의 출산지원금(요건 충족 시 전액).

**근로소득공제**는 자동으로 적용된다(서류 불필요, 한도 2,000만원).

| 총급여 | 근로소득공제 |
| --- | --- |
| 500만원 이하 | 총급여 × 70% |
| 500만원 초과 ~ 1,500만원 | 350만원 + 500만원 초과분 × 40% |
| 1,500만원 초과 ~ 4,500만원 | 750만원 + 1,500만원 초과분 × 15% |
| 4,500만원 초과 ~ 1억원 | 1,200만원 + 4,500만원 초과분 × 5% |
| 1억원 초과 | 1,475만원 + 1억원 초과분 × 2% |

근로소득금액 = 총급여 − 근로소득공제.

### ③ 소득공제 → 과세표준 → 산출세액

| 구분 | 항목 | 내용 |
| --- | --- | --- |
| 인적공제 | 기본·추가공제 | ① 참고 |
| 연금보험료공제 | 국민연금 | 본인 부담분 전액 |
| 특별소득공제 | 건강보험·장기요양·고용보험 | 본인 부담분 전액 |
| | 주택임차차입금 원리금 | 무주택 세대주의 전세자금대출 원리금 상환액 × 40%. 주택청약과 합쳐 연 400만원 한도 |
| | 장기주택저당차입금 이자 | 주택담보대출 이자 상환액. 상환 기간·방식에 따라 한도 600만~2,000만원(위 두 항목과 합산) |
| 그 밖의 소득공제 | 주택청약종합저축 | 총급여 7천만원 이하 무주택 세대주. 납입액(연 300만원 한도) × 40% |
| | 신용카드 등 사용액 | 5장에서 자세히 |
| | 기타 | 우리사주조합 출연금, 소기업·소상공인 공제부금(노란우산) 등 |

- 주택자금·청약·신용카드 등 일부 소득공제는 합쳐서 **연 2,500만원**을 넘을 수 없다(종합한도).
- 표준세액공제(④)와의 관계: 특별소득공제·특별세액공제·월세세액공제를 하나도 신청하지 않으면
  대신 13만원 표준세액공제를 받는다. 회사 정산 프로그램은 유리한 쪽을 고른다.

**과세표준** = 근로소득금액 − 소득공제 합계.

**산출세액** = 과세표준 × 기본세율(누진).

| 과세표준 | 세율 | 누진공제 |
| --- | --- | --- |
| 1,400만원 이하 | 6% | — |
| 1,400만원 초과 ~ 5,000만원 | 15% | 126만원 |
| 5,000만원 초과 ~ 8,800만원 | 24% | 576만원 |
| 8,800만원 초과 ~ 1억5천만원 | 35% | 1,544만원 |
| 1억5천만원 초과 ~ 3억원 | 38% | 1,994만원 |
| 3억원 초과 ~ 5억원 | 40% | 2,594만원 |
| 5억원 초과 ~ 10억원 | 42% | 3,594만원 |
| 10억원 초과 | 45% | 6,594만원 |

산출세액 = 과세표준 × 세율 − 누진공제. 예: 과세표준 3,000만원 → 3,000만 × 15% − 126만 = 324만원.

### ④ 세액감면·세액공제 → 결정세액

**세액감면**

- 중소기업 취업자 감면: 청년(15~34세) 등이 중소기업에 취업하면 5년간 소득세 90%
  감면(연 200만원 한도). 회사에 감면 신청서를 내야 적용된다.

**세액공제**

| 항목 | 내용 |
| --- | --- |
| 근로소득세액공제 | 자동 적용. 산출세액 130만원 이하분 × 55% + 초과분 × 30%. 한도는 아래 표 |
| 자녀세액공제 | 8세 이상 기본공제 대상 자녀·손자녀: 1명 25만원, 2명 55만원, 3명 이상 55만원 + 2명 초과 1명당 40만원. ⚠️ 2026년 귀속은 대상 나이가 바뀐다는 보도가 있다(아동수당 대상 확대에 맞춤) |
| 출산·입양 | 그 해 출산·입양한 자녀: 첫째 30만원, 둘째 50만원, 셋째 이상 70만원 |
| 연금계좌 | 연금저축 + IRP 납입액(합산 연 900만원, 연금저축만은 600만원 한도). 총급여 5,500만원 이하 15%, 초과 12%. ISA 만기 자금을 연금계좌로 옮기면 그 금액의 10%(최대 300만원) 추가 |
| 보험료 | 보장성 보험료 연 100만원 한도 × 12%. 장애인전용 보장성은 별도 100만원 × 15% |
| 의료비 | 총급여의 3% 를 넘는 금액 × 15%. 일반 부양가족은 연 700만원 한도. 본인·65세 이상·장애인·6세 이하 등은 한도 없음. 난임 시술 30%, 미숙아·선천성 이상아 20%. 실손보험으로 돌려받은 금액은 뺀다 |
| 교육비 | 15%. 본인은 대학원까지 한도 없음. 취학 전·초중고 1명당 300만원, 대학생 1명당 900만원. 취학 전 아동은 학원·체육시설 수강료도 포함. ⚠️ 2026년 귀속부터 초등 1~2학년 예체능 학원비 포함, 부양가족 교육비의 소득 요건 폐지가 보도되었다 |
| 기부금 | 정치자금·고향사랑기부금은 각각 10만원까지 100/110, 초과분 15%(고향사랑은 연 2,000만원까지 기부 가능). 일반 기부금은 1천만원 이하 15%, 초과 30% |
| 월세 | 무주택 세대주, 총급여 8천만원 이하, 국민주택규모(85㎡) 이하 또는 기준시가 4억원 이하 주택. 월세 연 1,000만원 한도. 총급여 5,500만원 이하 17%, 8,000만원 이하 15%. ⚠️ 2026년 귀속 한도·대상 변경 여부 확인 필요 |
| 혼인 | 2024~2026년에 혼인신고한 경우 생애 한 번 50만원(부부 각자) |
| 표준세액공제 | 특별소득공제·특별세액공제(보험료·의료비·교육비·기부금)·월세세액공제를 신청하지 않으면 13만원 |

근로소득세액공제 **한도**(총급여 기준):

| 총급여 | 한도 |
| --- | --- |
| 3,300만원 이하 | 74만원 |
| 3,300만원 초과 ~ 7,000만원 | 74만원 − (총급여 − 3,300만원) × 0.8%, 최소 66만원 |
| 7,000만원 초과 ~ 1억2천만원 | 66만원 − (총급여 − 7,000만원) × 50%, 최소 50만원 |
| 1억2천만원 초과 | 50만원 − (총급여 − 1억2천만원) × 50%, 최소 20만원 |

**결정세액** = 산출세액 − 세액감면 − 세액공제. 0 보다 작으면 0 이다.

### ⑤ 기납부세액

1년 동안 월급에서 떼인 소득세 합계(지방소득세 제외). 급여명세서의 소득세 칸을 더하거나,
연말정산 후 받는 원천징수영수증에서 확인한다. 그 해에 이직했으면 **종전 근무지 원천징수영수증**의
결정세액도 더한다. 종전 근무지 자료를 내지 않으면 5월에 직접 합산 신고해야 한다.

### ⑥ 결과

- 차감징수세액 = 결정세액 − 기납부세액. 음수면 그만큼 환급, 양수면 추가납부.
- 지방소득세 = 차감징수세액의 10%. 함께 환급되거나 함께 징수된다.
- 10원 미만은 버린다(국고금 끝수 처리). 지방소득세도 10% 를 계산한 뒤 10원 미만을 버린다.

## 5. 신용카드 등 소득공제 자세히

카드 공제는 계산 방식이 독특해서 따로 본다.

**1단계 — 문턱(최저사용금액)**: 총급여의 **25%** 까지 쓴 금액은 공제되지 않는다.
문턱을 채울 때는 **공제율이 낮은 신용카드 사용액부터** 쓴 것으로 본다.

**2단계 — 문턱을 넘은 금액 × 결제수단별 공제율**

| 결제수단 | 공제율 |
| --- | --- |
| 신용카드 | 15% |
| 체크카드·직불카드·현금영수증 | 30% |
| 도서·신문·공연·박물관·미술관·영화, 수영장·헬스장 이용료(총급여 7천만원 이하만) | 30% |
| 전통시장 | 40% |
| 대중교통 | 40% |

**3단계 — 한도**

| 총급여 | 기본 한도 | 자녀 추가 한도 (2026년 사용분부터) | 추가 한도(전통시장·대중교통·문화체육) |
| --- | --- | --- | --- |
| 7천만원 이하 | 300만원 | 자녀 1명당 50만원, 최대 100만원 | 합쳐서 300만원 |
| 7천만원 초과 | 250만원 | 자녀 1명당 25만원, 최대 50만원 | 전통시장·대중교통 합쳐서 200만원(문화체육 제외) |

- 자녀 추가 한도와 공제 일몰 연장(2028년 말까지)은 2025년 세제개편으로 2026년 사용분부터
  적용된다고 보도되었다. ⚠️ 법령 원문 확인 필요
- 공제되지 않는 사용액: 보험료, 세금·공과금, 아파트 관리비, 상품권 구입, 자동차 구입(중고차는
  구입액의 10% 만 사용액으로 인정), 해외 사용 등.
- **사용일 기준**이다. 12월에 쓰고 1월에 결제되는 금액은 그 해 사용액이다.

**연중 전략**

1. 총급여의 25% 까지는 혜택이 같으니 포인트·할인이 큰 신용카드를 쓴다.
2. 문턱을 넘은 뒤에는 체크카드·현금영수증(30%)이 신용카드(15%)보다 두 배 유리하다.
3. 기본 한도까지 다 채웠으면 결제수단을 바꿔도 공제가 늘지 않는다. 추가 한도(전통시장·대중교통·
   문화체육)만 남는다.

## 6. 계산 예시

**가정**: 총급여 5,000만원, 미혼, 부양가족 없음, 중소기업 감면 대상 아님.
국민연금 225만원 · 건강보험(장기요양 포함) 200만원 · 고용보험 45만원 납부.
신용카드 2,000만원 사용, IRP 300만원 납입, 1년간 원천징수된 소득세 240만원.
(4대보험 금액은 설명을 위한 가정이다.)

| 단계 | 계산 | 금액 |
| --- | --- | --- |
| ② 근로소득공제 | 1,200만 + (5,000만 − 4,500만) × 5% | 1,225만원 |
| ② 근로소득금액 | 5,000만 − 1,225만 | 3,775만원 |
| ③ 인적공제 | 본인 | 150만원 |
| ③ 연금보험료·보험료 공제 | 225만 + 200만 + 45만 | 470만원 |
| ③ 카드 문턱 | 5,000만 × 25% | 1,250만원 |
| ③ 카드 공제 | (2,000만 − 1,250만) × 15% = 112.5만, 한도 300만 이내 | 112만5천원 |
| ③ 과세표준 | 3,775만 − (150만 + 470만 + 112.5만) | 3,042만5천원 |
| ③ 산출세액 | 3,042.5만 × 15% − 126만 | 330만3,750원 |
| ④ 근로소득세액공제 | 계산값 71.5만 + (330.375만 − 130만) × 30% = 131.6만 → 한도 66만(총급여 5천만: 74만 − 13.6만 = 60.4만이지만 최소 66만) | 66만원 |
| ④ 연금계좌 | 300만 × 15% | 45만원 |
| ④ 결정세액 | 330.375만 − 66만 − 45만 | 219만3,750원 |
| ⑤ 기납부세액 | | 240만원 |
| ⑥ 차감징수세액 | 219.375만 − 240만 | **−20만6,250원 (환급)** |
| ⑥ 지방소득세 | 위 금액의 10% = 2만625원, 10원 미만 버림 | −2만620원 (환급) |

총 환급 예상 **22만6,870원**(약 22만7천원).

여기서 IRP 를 300만원 더(합계 600만원) 넣으면 세액공제가 45만원 더 늘어 결정세액은 174만3,750원이
된다. 환급은 소득세 65만6,250원 + 지방소득세 6만5,620원(6만5,625원에서 10원 미만 버림) ≈ 72만원으로 늘어난다.
결정세액이 아직 0 보다 크기 때문에 추가 공제가 그대로 환급으로 이어진다.

## 8. 용어

| --- | --- |

| 결정세액 | 산출세액 − 감면 − 세액공제. 실제로 내야 할 소득세 |

| 한계세율 | 내 과세표준이 걸친 마지막 구간의 세율. 소득공제 효과를 가늠할 때 쓴다 |
| 간소화 서비스 | 국세청이 카드·의료비·교육비 등 공제 자료를 모아 1월에 보여 주는 홈택스 서비스 |
| 경정청구 | 이미 끝난 정산에서 빠뜨린 공제를 5년 안에 다시 청구하는 절차 |
